How to Export JSON from Tally Prime
  1. Open Tally Prime → Go to Gateway of Tally
  2. Press Alt+E or select Export from the top menu
  3. Choose the data type: Vouchers / Ledgers / Stock Items / etc.
  4. Select Format: JSON from the export options
  5. Set the date range and click Export — save the .json file
  6. Upload that JSON file below (Step 1)
